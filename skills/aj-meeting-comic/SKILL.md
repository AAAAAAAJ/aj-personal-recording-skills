# 会议变漫画

## 人物参考图（可选）

上传一张**正面或半身参考图**可以让人物更像用户；未上传时使用文字描述或抽象角色即可，不阻塞本 Skill 的执行。是否使用真人形象由用户决定。


## 用途
将会议纪要转为角色对白与关键决定漫画。

## 执行流程
1. 读取指定日期可访问的 Codex、ChatGPT、本机 Work Agent 与目标平台记录。
2. 去重并区分本人行为、他人行为、计划和已核验结果。
3. 提炼主题，生成轻松、可直接阅读的成稿。
4. 生成与主题匹配的视觉卡片或结构化版式。
5. 写入用户选择的飞书或钉钉文档，并回查标题、日期、资源和来源。

## 案例
角色 A：先确认直播入口。角色 B：补齐共享音频。旁白：最终安排等待核对。

## 输出结构
- 日期与标题
- 一段简述
- 视觉卡片或图示
- 一个值得留下的瞬间
- 一个有依据的观察
- 下一步小事
- 简短来源链接与覆盖说明

## 边界
仅使用可访问且可核实的信息；未接入来源、缺失附件和未来计划单独标注，不补造事实。
