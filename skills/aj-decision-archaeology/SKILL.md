# 决策考古档案

## 人物参考图（无需上传）

本 Skill 的核心信息可以用事件、角色标签、图标或抽象人物完成，不要求用户上传个人形象。若用户希望加入本人形象，可自愿上传一张正面或半身参考图。


## 用途
保存重要决定、当时依据与后来结果。

## 执行流程
1. 读取指定日期可访问的 Codex、ChatGPT、本机 Work Agent 与目标平台记录。
2. 去重并区分本人行为、他人行为、计划和已核验结果。
3. 提炼主题，生成轻松、可直接阅读的成稿。
4. 生成与主题匹配的视觉卡片或结构化版式。
5. 写入用户选择的飞书或钉钉文档，并回查标题、日期、资源和来源。

## 案例
决定：采用轻松日记模板；依据：读者更容易阅读；后续：连续更新后保留了每日节奏。

## 输出结构
- 日期与标题
- 一段简述
- 视觉卡片或图示
- 一个值得留下的瞬间
- 一个有依据的观察
- 下一步小事
- 简短来源链接与覆盖说明

## 边界
仅使用可访问且可核实的信息；未接入来源、缺失附件和未来计划单独标注，不补造事实。
