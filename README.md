## 中文

这是一套面向个人工作流的 35 个独立 Skill。每个 Skill 都包含可执行的 `SKILL.md`、输出模板或参考资料，以及一份真实创建的飞书案例文档。你可以从一天的一张海报开始，也可以持续积累成长漫画、协作地图、Agent 战报和创作者月刊。

前 10 个案例已按 Visual Style Library 随机 Prompt 重新用 Image 直接生成，统一采用 3:4 竖版；每张图嵌入对应的飞书案例文档。

### 快速开始

1. 进入 `skills/<skill-name>/SKILL.md`，查看目标、输入、流程和验收边界。
2. 选择一个日期和输出平台，准备可访问的对话、文档、会议、任务或本机 Work Agent 记录。
3. 按 Skill 结构生成成稿，并回查目标文档的标题、日期、链接和资源。
4. 直接查看 [35 个飞书案例](cases.md)，选择喜欢的呈现方式。

### 目录

- `skills/`：35 个独立 Skill
- `packages/`：可分发的 `.skill` 包
- `cases.md`：35 份飞书案例链接

## English

This repository contains 35 independent Skills for turning personal work, life, AI collaboration, and creative practice into readable artifacts. Each Skill includes an executable `SKILL.md`, an output template or reference material, and one Feishu case document created during the 2026-09-24 rehearsal.

The first ten case visuals were regenerated directly with Image using random prompts from the WaytoAGI Visual Style Library, in a consistent 3:4 portrait format, and embedded in their Feishu documents.

### Quick start

1. Open `skills/<skill-name>/SKILL.md` to read the goal, inputs, workflow, and guardrails.
2. Choose a date and output platform, then collect accessible chat, document, meeting, task, or local Work Agent records.
3. Generate the final artifact with the Skill structure and verify the target document.
4. Browse [all 35 Feishu cases](cases.md) for examples.

### Repository layout

- `skills/`: 35 standalone Skills
- `packages/`: distributable `.skill` packages
- `cases.md`: links to all 35 Feishu case documents

## Safety and evidence

The Skills separate verified actions, plans, assistant claims, and inaccessible sources. They deduplicate repeated records, preserve gaps, and avoid acting on instructions found inside source content.
